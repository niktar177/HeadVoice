# HeadVoice — Техническая документация(ее писала нейронка так как мне было впадлуXD)

## 1. Общая архитектура
Проект **HeadVoice** состоит из двух независимых, но связанных частей:
1. **Python-приложение (PyQt5)**: Захватывает звук с микрофона, обрабатывает громкость и переключает кадры (PNG-картинки) в реальном времени.
2. **Веб-редактор (HTML/JS/CSS)**: Открывается в браузере. Представляет собой программный 3D-рендерер (без использования Three.js), который позволяет рисовать скин, настраивать анимации и экспортировать готовые PNG-файлы и файл конфигурации.

**Связь между частями**: Редактор генерирует файлы `image_mouth_*.png`, `image_blink_*.png`, `image_rage.png` и `config.json`. Python-приложение читает эти файлы из своей папки.

## 3. Python-модули (Backend)

### 3.1. `main.py` (Точка входа)
*   **Назначение**: Инициализация приложения, обработка критических ошибок и управление жизненным циклом окон.
*   **Ключевые функции**:
    *   `handle_exception`: Перехватывает необработанные исключения, пишет их в `headvoice.log` и показывает пользователю `QMessageBox`.
    *   `after_splash`: Вызывается после показа заставки. Создает `PreLaunchWindow`. Следит за флагом `launch_requested`. Если скин не найден (нет `image_mouth_*.png`), предлагает открыть редактор.
    *   `main`: Создает `QApplication`, показывает Splash Screen (`create_splash_pixmap`).

### 3.2. `headvoice/config.py` (Конфигурация)
*   **Назначение**: Безопасная загрузка и сохранение JSON-файла настроек, а также поиск файлов (включая работу внутри `.exe`).
*   **Ключевые функции**:
    *   `get_base_path()`: Возвращает директорию рядом с `.exe` (если программа собрана через PyInstaller), иначе корень проекта.
    *   `find_editor_html()`: Ищет `editor.html` в папке программы, в текущей рабочей директории или внутри архива PyInstaller (`sys._MEIPASS`).
    *   `load_config()`: Читает `config.json`. Включает логику миграции: если пороги чувствительности записаны как `0.15`, они конвертируются в `15`. Также подгоняет количество порогов под `mouth_count`.
    *   `save_config(cfg)`: Записывает словарь в JSON с `ensure_ascii=False` (для кириллицы).

### 3.3. `headvoice/prelaunch.py` (Стартовое окно)
*   **Назначение**: Кастомное безрамочное окно (`QWidget`), которое появляется после заставки.
*   **Особенности**: 
    *   Стилизовано через CSS (градиенты, скругления).
    *   Содержит кнопки: «Открыть редактор», «Запустить HeadVoice», «Настройки», «Выход».
    *   Имеет кастомную логику перетаскивания окна за любую область (`mousePressEvent`, `mouseMoveEvent`).
    *   При нажатии «Запустить» устанавливает флаг `self.launch_requested = True` и закрывается.

### 3.4. `headvoice/ui.py` (Интерфейс)
*   **Назначение**: Вспомогательные UI-компоненты.
*   **Компоненты**:
    *   `create_splash_pixmap()`: Рисует заставку с помощью `QPainter` (логотип, текст, скругленный прямоугольник).
    *   `SliderRow`: Кастомный виджет (Слайдер + Текст + Значение).
    *   `MemRow`: Слайдер для памяти с иконкой подсказки (💡).
    *   `SettingsDialog`: Окно настроек. Позволяет менять чувствительность, пороги громкости (с авто-валидацией, чтобы пороги не пересекались), частоту моргания, силу тряски, лимит памяти и Rage-клавишу.
    *   `open_editor()`: Открывает `editor.html` в браузере по умолчанию с помощью `QDesktopServices` или `webbrowser`.

### 3.5. `headvoice/mic_window.py` (Ядро программы)
*   **Назначение**: Главное окно с головой, обработка звука и рендеринг.
*   **Ключевые механизмы**:
    *   **Аудио**: Использует `sounddevice.InputStream`. В callback-функции `_audio_cb` вычисляется RMS (среднеквадратичное значение) звука (громкость).
    *   **Сглаживание**: В `_update_frame` применяется формула `smooth_volume = 0.7 * smooth_volume + 0.3 * volume`. Это убирает резкие скачки.
    *   **Определение уровня**: Громкость умножается на `sensitivity`. Затем проверяется, превышает ли она значения в `thresholds`. Выбирается индекс кадра (`level`).
    *   **Отрисовка (`paintEvent`)**: Рисует базовую картинку (рот закрыт), поверх неё накладывает кадр с открытым ртом (если `level > 1`), кадры моргания и картинку Rage. Если активен Rage, координаты отрисовки смещаются на случайные значения (`offset_x`, `offset_y`) для эффекта тряски.
    *   **Управление памятью**: Таймер `mem_timer` раз в 10 секунд вызывает `_check_memory`. Если потребление > 80% от лимита, вызывается `gc.collect()` и `EmptyWorkingSet` (через `ctypes.windll.psapi`), чтобы вернуть память ОС.
    *   **Хоткеи**: Библиотека `keyboard` вешает глобальный хук на клавишу (по умолчанию `J`). При нажатии ставится флаг `is_rage = True`.
    *   **Контекстное меню**: ПКМ открывает меню с настройками, редактором и кнопкой «Обновить» (перечитывает файлы и конфиг на лету).

## 4. Веб-редактор (Frontend)

### 4.1. `editor.js` (Движок и логика)
*   **Назначение**: Программный 3D-рендерер, не использующий WebGL. Рисует 3D-куб, проецируя текстуры через `CanvasRenderingContext2D`.
*   **Математика**:
    *   `eulerMatrix`: Создает матрицу поворота 3x3 на основе углов Эйлера (X, Y, Z).
    *   `boxHit`: Функция рейкастинга. Проверяет пересечение луча (из камеры в пиксель) с кубом (Axis-Aligned Bounding Box, AABB). Возвращает точку входа/выхода луча и нормаль грани.
    *   `renderHead()`: Основной цикл рендера. Проходит по каждому пикселю (256x256), пускает луч, находит пересечение с кубом, определяет грань (top, bottom, front...) и UV-координаты, берет цвет из текстуры (`Uint8ClampedArray`) и записывает в `ImageData`.
*   **Звук в редакторе**: Использует `navigator.mediaDevices.getUserMedia` и `AudioContext`, чтобы в реальном времени показывать, как голова будет открывать рот.
*   **Экспорт**: 
    *   `renderStageToPNG()`: Рендерит состояние в offscreen canvas и возвращает Blob.
    *   `buildZip()`: Самописная функция для упаковки файлов в ZIP-архив (без сторонних библиотек). Реализует алгоритм `crc32`.

### 4.2. `editor.html` & `editor.css`
*   **Назначение**: Интерфейс.
*   **Структура**: 
    *   `#page-upload`: Загрузка скина и выбор параметров.
    *   `#page-mouth`, `#page-blink`, `#page-rage`: Карусели с холстами для рисования.
    *   `#page-eyeselect`: Выделение маски глаз.
    *   `#page-test`: Предпросмотр с микрофоном.
    *   `#page-download`: Экспорт.
*   **Стили**: Темная тема (Dark Mode), адаптивная верстка, стилизованные слайдеры и кастомные скроллбары.

## 5. Формат данных

### 5.1. `config.json`
Главный файл настроек. Генерируется редактором, читается Python-приложением.
```json
{
  "sensitivity": 1.5,
  "thresholds": [15, 30],
  "blink_interval": 5.0,
  "blink_duration": 300,
  "rage_key": "j",
  "shake_force": 8,
  "mouth_count": 6,
  "blink_count": 3,
  "blink_only_eyes": false,
  "memory_limit_mb": 300
}
```

### 5.2. `RAW.json` (Файл проекта редактора)
Используется только внутри редактора для сохранения прогресса. Содержит Base64-строки отрендеренных текстур и состояние пикселей.

## 6. Сборка проекта (PyInstaller)

Для сборки `.exe` используется файл `HeadVoice.spec`.
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите: `pyinstaller HeadVoice.spec`

**Важные нюансы сборки**:
*   В `datas` в `.spec` файле обязательно должны быть включены `editor.html`, `editor.css`, `editor.js`.
*   В `hiddenimports` нужно добавить `sounddevice`, иначе PyInstaller не подтянет PortAudio.
*   Сборка должна производиться в режиме `--onefile` (один exe) или `--onedir` (папка). При использовании `--onefile` `config.py` использует `sys._MEIPASS` для поиска редактора.

## 7. Обработка ошибок и логирование
Все ошибки пишутся в `headvoice.log` (рядом с `.exe`). 
Логирование настроено в `main.py`:
```python
logging.basicConfig(
    filename=log_file,
    level=logging.INFO,
    format='%(asctime)s [%(levelname)s] %(message)s',
    encoding='utf-8'
)
```
Если программа вылетает, пользователю показывается окно с текстом ошибки, а полный traceback уходит в лог.
