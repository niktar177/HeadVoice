# HeadVoice
Говорящий скин майнкрафт(как у PWGood и даже лучше) . С использованием анимации моргания и полностью адаптированный под стримы,а так же с редактором анимаций

Данный репозиторий представляет собой открытый исходный код приложения HeadVoice .
Сама программа в exe формате лежит в релизах. Редактор в нее не зашит и его можно скачать как в тг так и с гитхаба выше(вам нужны editor_js editor.css editor.html запускается через editor.html)
Если же вы хотите скачать саму программу и не возится с ее сборкой и прикольчиками для разработчиков, то все релизы публикуются тут : https://t.me/cyhdoochok_twitch
